にゃんにゃん本棚 利用規約

施行日 2026年11月7日

本書は、日本在住のお客様向けの日本語版です。韓国語版と内容が異なる場合は、日本の消費者保護法令の強行規定が適用される場合を除き、韓国語版が優先します。

ひと目でわかる要点

  • 主な機能は無料：本の記録、引用の撮影、読書タイマー、ネコ、バックアップ、フィードは、制限なく無料です。有料なのは、シェアカードの追加テンプレート、人物相関図の3人目以降、タググラフの3つ目以降、プレミアムにゃんこだけです。
  • 支払いは1回だけ：有料機能は1回の購入でずっと使えます。サブスクリプションも広告もありません。
  • ログインは任意：ログインしなくても、本の登録・引用の記録・読書タイマーはそのまま使えます。
  • 記録はあなたのもの：書いた引用やメモの著作権はお客様にあり、運営者は取得しません。
  • 記録は端末に保存されます：アプリを削除すると端末の記録も消えます。設定＞「記録を保管する」で事前にバックアップしてください。
  • フィードには公開を選んだ投稿だけ。不快な投稿は容赦しません。通報は24時間以内に対応し、3件たまった投稿は自動で非表示になります。

第2条 用語の定義

第7条 返品・キャンセル・返金

  4. 返金の申請は、決済を処理したAppleまたはGoogleに直接行います。アプリ内課金の仕組み上、当社が代金を直接返金することはできないためです。

第8条 ユーザーの投稿等の著作権

  1. ユーザーが書いたメモ・感想・ニックネームなどの著作権は、ユーザー本人に帰属します。当社はこれに関する権利を取得しません。
  2. ユーザーがフィードへの公開を選んだ投稿に限り、当社は、フィードの提供・表示・運営に必要な範囲でのみ、その投稿を保存・複製・送信できます。この範囲を超える利用（外部向けの宣伝物の作成、第三者への提供、販売など）は、ユーザーの別の同意なしには行いません。
  3. ユーザーが公開を取り消したり元の投稿を削除したりすると、この利用権限も同時に消え、投稿はフィードから下がります。
  4. 公開した時点の書名と著者は投稿にコピーして保存されるため、あとからユーザーが本の情報を直したり削除したりしても、すでに公開された投稿には公開当時の内容が残ります。

第9条 引用した著作物についてのユーザーの責任

  1. 本アプリは、本の一節を撮影・記録する機能を提供します。記録された本の本文の著作権は、その本の権利者にあり、当社やユーザーの著作物ではありません。
  2. 端末にだけ保存して個人的に見ることは、通常は私的使用にあたります。一方、フィードへの公開は公衆送信にあたります。公開するときは、著作権法第32条が定める「引用」の範囲（公正な慣行に合致し、引用の目的上正当な範囲内で、出所を明示すること）を守ってください。
  3. 正当な引用の範囲を超えて著作物を公開したことで生じた法的責任は、そのユーザーが負います。
  4. 権利者から削除の申出があった場合、当社は該当の投稿を遅滞なく削除またはアクセス遮断し、投稿者に知らせます。

第10条 フィードへの公開と投稿の管理

  1. ユーザーの投稿は、ユーザー自身が公開を選んだ場合にだけフィードに載ります。当社が勝手に投稿を公開することはありません。
  2. フィードに表示されるのは、引用のテキスト、メモ、ニックネーム、公開時点の書名・著者です。写真、ページ番号、メールアドレスは表示されません。
  3. ユーザーはフィード画面でいつでも公開を取り消せます。
  4. 他のユーザーの投稿につけた「いいね」は、サービスの提供のためにサーバーに保存されます。

第11条 禁止事項と容赦しない方針

ユーザーは次の行為をしてはなりません。

  1. 法令・公序良俗に違反する、または犯罪に利用されるおそれのある内容の投稿
  2. 他人への侮辱・脅迫・誹謗中傷、名誉を傷つける内容の投稿
  3. わいせつな内容、暴力的・差別的な内容の投稿、性別・地域・人種・障害・宗教などに対する差別や憎悪の表現
  4. 他人の著作権・肖像権その他の権利を侵害する内容の投稿
  5. 他人の個人情報を同意なく掲載・収集する行為
  6. 広告・宣伝・スパム目的の繰り返しの投稿
  7. 他人のアカウントの不正利用、他人へのなりすまし
  8. サービスの正常な運営の妨害、アプリの解析（リバースエンジニアリング）、サーバーへの不正アクセス
  9. 自動化された手段によるフィード投稿の大量収集・複製

当社は、上記に当たる投稿・行為に対して容赦しない（ゼロ・トレランス）方針をとります。該当する投稿は、事前の通知なしに削除または他のユーザーに見えない状態にすることがあり、繰り返した場合や程度が重い場合は、アカウントの利用を制限することがあります。

第12条 通報・ブロックと運営者の対応

  1. ユーザーはフィード画面で、他のユーザーの投稿を通報したり、そのユーザーをブロックしたりできます。
  2. 通報した投稿は、通報したユーザーにはすぐに見えなくなります。ブロックしたユーザーの投稿も同様にすぐ見えなくなります。ブロックしたユーザーの一覧は、設定＞「ブロックしたユーザー」で確認・解除できます。
  3. 1つの投稿に通報が3件以上たまると、その投稿は自動的に非表示になり（自動処理です）、すべてのユーザーに見えなくなります。そのあと、当社が内容を確認します。
  4. 当社は、受け付けた通報を確認し、24時間以内に、投稿の削除、表示の遮断、投稿者の利用制限など必要な措置をとります。
  5. 確認の結果、本規約に違反していないと分かった投稿は、非表示を解除することがあります。
  6. 投稿が違法だと考える方（ユーザーでない方を含みます）は、sokurihj@gmail.com に、投稿の所在（引用のテキストとニックネームで足ります）、違法だと考える理由、ご自身のお名前とメールアドレス、そして記載内容が正確かつ完全であると誠実に信じていることをお知らせください。当社は遅滞なく対応します。
  7. 当社が理由を示して投稿やアカウントに措置をとった場合、その理由には、自動処理（通報3件での自動非表示）が関わったかどうかも含めます。お客様はメールで異議を申し立てられます。当社は遅滞なく再確認し、説明が相当と認めるときは措置を解除します。

第13条 データの保存とユーザーの責任

  1. アプリの記録は、基本的にユーザーの端末の中に保存されます。アプリを削除したり、端末を初期化・紛失したり、端末が故障したりすると、保存された記録が消えることがあります。
  2. 写真は端末にだけ保存され、サーバーにはバックアップされません。ただしAndroidでは、文字認識のために写真を一時的にGoogleへ送ります（保存しません。プライバシーポリシーをご覧ください）。読書時間、読了とネコの記録もサーバーにはバックアップされません。
  3. 会員としてログインした場合は、本（タイトル・著者・ISBN・表紙アドレス）と、引用・メモ・単語帳（本文・ページ番号・メモ）がサーバーにバックアップされ、機種変更のときに復元できます。ただし、このバックアップは付加機能であり、当社はバックアップデータの永久の保存を保証しません。
  4. 大切な記録を失わないよう、設定＞「記録を保管する」で定期的にファイルバックアップを作り、別の場所に保管することをおすすめします。
  5. ユーザーがバックアップを怠ったために生じたデータの損失について、当社は責任を負いません。ただし、当社の故意または過失による損失は除きます。

第14条 サービスの変更・中断

  1. 当社は、サービスの内容を変更したり、一部の機能を追加・終了したりできます。ユーザーに不利益となる重要な変更は、第3条の手順で事前に告知します。
  2. サーバーの点検・交換やシステム障害、外部サービス（認証・保存・検索API など）の障害や方針変更、天災などの不可抗力があった場合は、サービスの提供を一時中断することがあります。
  3. サービスを完全に終了するときは、少なくとも30日前までに告知し、記録をバックアップする方法を案内します。
  4. サービスが中断しても、ログインなしで端末の中で動く機能は引き続き使えます。

第15条 退会と利用制限

  1. 会員はいつでも設定＞「退会」から利用契約を解約できます。
  2. 退会すると、サーバー上のアカウント情報、バックアップデータ、フィード投稿、「いいね」・通報・ブロックの記録がすぐに削除され、復元できません。
  3. 端末に保存された記録は、退会では削除されません。端末の記録まで消すには、アプリを削除してください。
  4. 購入した有料機能は、退会の影響を受けません。購入履歴はアプリのアカウントではなくお客様のAppleまたはGoogleのアカウントに結び付いているため、退会後やログインしていない状態でも、同じストアアカウントなら「購入の復元」でそのまま使えます。
  5. ユーザーが第11条の禁止事項を行った場合、当社は事前通知なしに、投稿の削除、フィードの利用制限、アカウントの利用停止などの措置をとることがあります。
  6. 前項の措置に異議があるユーザーは、第12条第7項のとおりメールで説明でき、その説明が相当と認められれば措置は解除されます。
