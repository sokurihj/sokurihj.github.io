施行日 2026年11月8日（告知日 2026年11月1日）。それまでは改定履歴の直前の施行内容（2026年11月4日施行、その前日までは2026年10月29日施行）が適用されます。ただし、第4条の本の検索先・書誌情報の補完先の変更は、これを反映したアプリのアップデートの配信日から適用されます。また、Androidの文字認識で使う無作為の端末番号とGoogle ML Kitの診断情報に関する記載はAndroidアプリの公開と同時に、2026年10月25日から適用されます。

本書は、日本在住のお客様向けの日本語版です。韓国語版と内容が異なる場合は、日本の法令の強行規定が適用される場合を除き、韓国語版が優先します。

ひと目でわかる要点

  • 取得するもの：必須で取得する個人情報はありません。ログインを選んだ場合のみ、メールアドレス・アカウント識別子・ニックネームを取得します。ログインすると、本・引用・メモ・単語帳もバックアップします。
  • しないこと：広告・解析・トラッキング用のSDKは使いません。Cookieも使いません。個人情報を販売しません。写真は当社のサーバーに保存しません。
  • ログインなしでも：本の登録、引用・メモの記録、読書タイマー、ネコ集めは、ログインしなくても端末の中でそのまま使えます。
  • フィードに公開すると：ご自身が公開を選んだ投稿だけが、ニックネームとともに他のユーザーに表示されます。公開を取り消すとフィードから下がります。
  • データを持ち出す：設定＞「記録を保管する」から、記録をすべてファイルに書き出せます。
  • 退会すると：サーバー上のアカウント・バックアップ・フィードのデータはすぐに削除されます。端末に残ったデータは、ご自身で削除するかアプリを削除すると消えます。
  • お問い合わせメール：メールでお問い合わせいただいた場合、回答と記録のためにメールアドレスとお問い合わせ内容を保管します（回答後3年、Gmailを利用）。
  • お問い合わせ：sokurihj@gmail.com

解析・広告・クラッシュレポートのツールは使いません。自動的に記録するのはAndroidでの文字認識に限られ、認識を依頼するときにアプリが自分で作った無作為の端末番号を送り、悪用を防ぐための1日の利用回数の制限のために、この番号と1日の利用回数を3日間だけサーバーに保管して削除します。メールアドレス・ニックネーム・写真・アカウントとは結び付けず、広告や追跡には使わず、アプリを削除すると新しい番号に変わります。また、Androidで端末内の文字認識を使うときは、Google ML Kitは写真や認識した文字は送りませんが、機能の診断と利用分析のため、端末情報（メーカー・機種・OSバージョン）、アプリ情報（パッケージ名・バージョン）、インストールごとの識別子（ご本人や端末を特定しない値）、性能指標・エラーコードをGoogleに送ることがあります。この情報はGoogleのプライバシーポリシーに従って取り扱われます。iOSではいずれも行いません。送信を望まない場合：端末番号と診断情報は、Androidで写真の文字認識を使うときだけ送られます。文字認識を使わず引用を手で入力すれば何も送られず、ほかの機能はそのまま使えます。サーバーに残った端末番号は3日後に自動で削除されます。要配慮個人情報は意図して取得しません。引用やメモはご自身が自由に書き込む文章ですので、保存を望まない機微な情報は入力しないでください。

カメラ（引用の撮影・バーコードの読み取り）、写真（フォトライブラリから本の写真を選ぶ）、通知の権限はいずれも任意です。許可しない場合は、その機能だけが使えなくなります。

カメラ・写真・文字認識

  • iOS：写真の中の文字は、端末の中でAppleのVisionによって認識します。写真が外部に出ることはありません。
  • Android：文字を正確に読み取るため、認識を依頼するたびに、写真を当社のサーバー関数（Supabase）経由でGoogle Cloud Vision（Google LLC）に送ります。当社は写真を保存せず、認識結果の文字だけをアプリに返します。Googleは、この方式では画像をディスクに保存せずメモリ上で処理し、モデルの学習には使わないとしています。インターネットに接続していない場合や、このサービスの1日の処理上限に達した場合は、端末内のGoogle ML Kitで認識するため、写真は外部に出ません。Google ML Kitは写真や認識した文字は送りませんが、機能の診断と利用分析のため、端末情報（メーカー・機種・OSバージョン）、アプリ情報（パッケージ名・バージョン）、インストールごとの識別子（ご本人や端末を特定しない値）、性能指標・エラーコードをGoogleに送ることがあります。この情報はGoogleのプライバシーポリシーに従って取り扱われます。
  • Android：1台の端末が1日に使える文字認識の回数を制限するため、認識を依頼するときにアプリが自分で作った無作為の端末番号も一緒に送ります。この番号はご本人と結び付かず、アプリを削除すると変わります。サーバーは、この番号と1日の利用回数を記録した日から3日間だけ保管して削除します。

通知

読書タイマーに目標時間を設定して始めるとき、時間になったことをお知らせするため通知の許可をお願いします。許可しなくてもタイマーは使えます（通知が鳴らないだけです）。通知は端末の中だけで予約され、サーバーには何も送りません。リモート（プッシュ）通知は使わず、プッシュ用の端末識別情報も作成・取得しません。

有料機能の決済

一部の機能は、1回かぎりのアプリ内課金です。決済はApple App StoreまたはGoogle Playが行い、当社は決済手段の情報や取引の記録を取得・保管しません。取引の記録は決済を処理したAppleまたはGoogleが保有し、各ストアの購入履歴で確認できます。

第11条 安全管理措置

  • ログインのセッション情報は、端末のセキュアストレージに保管した鍵でAES-256により暗号化して保存します。
  • サーバーとの通信はHTTPSで暗号化されます。
  • サーバー上のデータは、アクセス制御（Row Level Security）により、ご本人のデータ（および他のユーザーが公開した投稿）にしかアクセスできないようにしています。
  • サーバーへのアクセス権限は運営者本人のみに付与し、管理用の認証情報はアプリのコードに含めません。
  • 個人情報を取り扱う者は運営者1名にとどめ、利用目的を達成したデータは遅滞なく削除します。お問い合わせメールは運営者本人だけがアクセスできるアカウントで管理します。
  • 外的環境の把握：運営者は大韓民国（個人情報保護法があります）で個人データを取り扱い、第8条のとおり米国などでも取り扱われます。これらの国の個人情報保護に関する制度を把握したうえで安全管理措置を講じています。
  • 広告・解析・クラッシュレポートのツールはアプリに組み込みません。ただし、Androidの端末内の文字認識（Google ML Kit）はGoogleに診断情報を送ることがあります。

第12条 Cookieその他の技術

本アプリは、Cookie、広告識別子（IDFA／GAID）、トラッキング技術を使いません。本ポリシーのページは静的なウェブページで、独自のCookieも設定しません。
